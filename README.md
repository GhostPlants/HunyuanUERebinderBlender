# 混元 → UE 骨架换绑助手 v1.4

Hunyuan UE Rebinder 是一个 Blender Add-on，用于将已有蒙皮的混元、Mixamo 或相似人形角色换绑到 Unreal Engine 人形骨架，例如 Manny、Quinn 或结构相近的自定义骨架。

插件保留源模型，所有对齐、修复和换绑操作都在副本上完成。它可以迁移现有权重、混合 UE 参考网格权重、检查常见网格问题，并导出适合 UE 导入的 FBX。

## v1.4 的主要变化

步骤 3 新增并完善了 **仅匹配姿势，保留体型** 模式。该模式默认启用 **骨架贴合模型（保留 UE 骨骼方向）**：

- 先旋转源角色的骨段，使 T Pose、A Pose 等姿势接近目标 UE 骨架。
- 保留源角色的骨长与主要体型，不按 UE 模板强行拉长躯干或缩放四肢。
- 将输出骨架的已映射关节移动到源关节位置，使肩、肘、髋、膝等旋转中心贴近模型。
- 保留 UE 骨名、父子层级以及世界和局部参考旋转，只调整参考位移。
- 根据贴合后的目标骨架迁移权重；使用混合权重时，UE 参考表面会在内存中随新关节位置适配，原参考网格不会被修改。
- 检查与导出报告记录 `pose_alignment` 和 `translation_retargeting_required`。

贴合位置来自源骨架关节，不是从网格表面自动识别人体结构。源骨架的关节位置不准确时，应先修正源骨架。

## 重要概念

### 网格对齐、骨架贴合和权重

- **网格对齐**决定角色参考姿势与外形。
- **骨架贴合**决定骨骼旋转中心是否位于模型的肩、肘、髋、膝等关节处。
- **蒙皮权重**决定每个顶点受到哪些骨骼影响，以及影响比例。

权重不能移动骨骼的旋转中心。如果骨骼膝关节与模型膝盖相差很远，重新刷权重仍可能从错误位置弯曲。因此，大体型差异角色优先使用 v1.4 的“仅匹配姿势 + 骨架贴合模型”。

### 骨架尾端不一定指向子关节

骨架贴合模式会整体平移每根 UE 骨骼，以保留其参考旋转方向。Blender 中某些骨骼的显示尾端可能没有正好连接到子骨骼头部，这是有意行为。不要再运行自动骨骼朝向或重新计算 Roll，否则可能破坏 UE 动画需要的参考方向。

## 三种对齐方式

| 对齐方式 | 网格体型 | 输出骨架 | 适合情况 |
| --- | --- | --- | --- |
| 自动适配目标参考姿势 | 按目标关节和比例调整，体型可能明显变化 | 保持目标 UE 参考骨架 | 源角色与 UE 模板比例接近 |
| 已手工对齐，保持网格 | 不再自动调整 | 保持所选目标骨架 | 已经自行完成姿势和外形调整 |
| 仅匹配姿势，保留体型 | 旋转骨段，保留源骨长与主要比例 | 默认让关节贴合模型并保留 UE 骨骼方向 | 源角色与 UE 模板比例差异较大 |

在第三种模式中关闭 **骨架贴合模型** 后，输出骨架保持原目标位置。这适合关节差异较小的角色。预览会显示关节偏差；较大偏差不能只靠权重补偿。

## 安装

1. 找到 `hunyuan_ue_rebinder_v1.4.0.zip`，不要解压。
2. 打开 Blender → **编辑（Edit）→ 偏好设置（Preferences）→ 插件（Add-ons）**。
3. 使用右上角菜单选择 **从磁盘安装（Install from Disk）**。
4. 选择 ZIP，并启用 **混元 → UE 骨架换绑助手**。
5. 回到 3D 视图，按 `N`，打开 **UE 换绑** 页签。

插件声明最低 Blender 4.2；完整测试环境为 Windows Blender 5.2.1 LTS。

### 从旧版本升级

先保存场景，禁用旧版插件，再安装 v1.4 并重启 Blender。旧预览和旧换绑结果不会自动更新；升级后应重新执行步骤 3、3.5、4 和 5。

如果旧预览经过手工编辑，请先另存 `.blend` 备份。不要把旧版生成的 `UE_体态参考_需独立Skeleton` 当作 v1.4 骨架贴合模式的目标输入。

## 推荐工作流

### 1. 选择输入

在 **UE 换绑** 面板中选择：

- **UE 骨架**：目标 Armature，或仅包含一套目标骨架的外层 Empty。
- **混元骨架**：源角色的 Armature。
- **UE 参考网格**：可选。插件优先自动选择目标骨架下名称含 LOD0 的网格。

点击 **1. 检查输入并识别网格**。插件通过 Armature 修改器查找源网格，不依赖网格对象名称。多个身体、衣服或头发网格可分别启用。

输入要求：

- 源网格已有有效蒙皮权重。
- 两套骨架必须独立。
- 骨架对象不能存在负缩放、零缩放或非均匀缩放。
- 不能把插件生成的预览或结果再次作为输入。
- 源网格带 Shape Keys 时，只有启用 **烘焙当前形态（不保留形态键）** 才能继续；原始网格仍会保留。

### 2. 检查骨骼映射

映射表左侧是源骨骼，右侧是目标骨骼。重点检查骨盆、脊柱、颈部、头部、锁骨、上臂、前臂、手、大腿、小腿、脚和脚趾。

- 所有实际参与蒙皮的源骨骼都必须映射。
- 不要把变形权重映射到 IK、武器或辅助骨。
- 普通模式允许多根源骨合并到同一目标骨。
- **骨架贴合模型**要求一对一关节映射；重复目标会阻止生成。
- 源角色没有独立手指骨时，插件保留整手绑定，不会猜测每根手指的权重。

完成后点击 **2. 检查映射**。可以保存和加载 JSON 映射预设，但加载后仍应人工复核。

### 3. 生成对齐预览

对于体型差异较大的角色，推荐：

1. 对齐方式选择 **仅匹配姿势，保留体型**。
2. 保持 **骨架贴合模型（保留 UE 骨骼方向）** 开启。
3. 点击 **3. 生成 / 更新对齐预览**。
4. 检查正面和侧面，重点观察肩、肘、手腕、髋、膝、脚踝、头颈和脚底。

该模式以骨盆为整体定位点，旋转骨段但不缩放源骨长。已映射的输出关节贴合源关节；额外脊柱、颈部和辅助关节沿相应骨段插值，常见手脚 IK 末端随手脚定位。

预览位于 `换绑_对齐预览` 集合。可以在编辑模式调整预览网格，后续绑定会保留这些编辑。不要移动或旋转预览骨架。

自动适配模式下可以调整头部比例、头部定位、手部粗细和拟合稳定强度。仅匹配姿势模式不会使用这些缩放参数，以免再次改变体型。

### 3.5 检测与修复网格

将 **检测对象** 设为 **对齐预览**，运行检测。插件会检查：

- 退化面与重复索引面；
- 游离顶点；
- 非流形边与边界；
- 小型独立网格岛；
- 具有拟合参考数据时的疑似翻折和异常面积变化。

检测结果是筛查提示，不是完整的自相交检测。头发、饰品和护甲可能本来就是独立网格岛，不应一律删除。

修复操作发生在副本上，并保存修复前 Mesh 数据。默认不会全局焊接、自动补洞或删除小岛。肩甲、袖口、胸部、腋下、裆部、裙甲与鞋底仍需人工观察。

### 4. 生成换绑模型

| 权重方式 | 行为 | 建议 |
| --- | --- | --- |
| 仅迁移原权重 | 按映射将源顶点组迁移到目标骨骼 | 骨架贴合模式的首选起点；平滑次数先设为 0 |
| 原权重 + UE 参考权重 | 按身体区域混合目标参考网格权重 | 源表面与参考表面相近时使用；厚衣服和护甲应降低混合比例 |

骨架贴合模式下，目标参考网格仅在内存中按新关节位置适配后用于采样，原 UE 网格不会改变。

点击 **4. 生成换绑模型** 后，结果写入 `换绑_结果` 集合。UV、材质和源网格拓扑保留。建议先检查原权重迁移结果，再通过 Weight Paint 局部修正肩、肘、手腕、髋、膝、脚踝和服装刚性区域。

### 5. 检查骨架和动作

插件提供参考、抬臂、仅上臂压力、弯肘、屈膝和转头测试。它们用于快速发现蒙皮问题，不代表真实 UE 动画、IK 或脚底接地测试。

重点检查：

- 肩部是否被胸部或锁骨错误拖拽；
- 手肘和膝盖是否从正确位置弯曲；
- 左右腿是否串权重；
- 裙甲、护肩和袖口是否需要更刚性的权重；
- 脚底和脚趾是否出现拉长、翻转或离地；
- 手指是否有实际源权重。

点击 **5. 检查骨架和权重**。检查内容包括骨名、层级、参考矩阵、根骨数量、Armature 修改器、未赋权顶点、权重归一化、每顶点影响数量与基础网格健康状态。

### 6. 导出 FBX

导出使用独立临时副本，不改变当前场景：

- 单位转换为厘米；
- 输出参考姿势，不输出当前测试姿势或测试动画；
- 保留目标全部骨骼；
- 不添加叶骨；
- 可内嵌贴图；
- 生成同名 `.report.json` 检查报告。

## 导入 Unreal Engine

### 固定 UE 参考骨架的结果

自动适配模式、手工对齐模式，以及关闭“骨架贴合模型”的仅匹配姿势模式，输出骨架应与所选目标参考骨架一致。

导入时选择目标角色实际使用的现有 Skeleton。关闭 **Update Skeleton Reference Pose**，不要用导入文件覆盖共享 Skeleton 的参考姿势。文件不含动画时不要启用 Import Animations。

### 骨架贴合模型的结果

该结果保留 UE 骨名、层级和参考旋转，但骨骼参考位移按照角色体型改变。要使用同一 Skeleton 的现有动画，必须正确设置 UE 的 Bone Translation Retargeting：

- 普通身体骨通常设为 **Skeleton**；
- pelvis 通常设为 **AnimationScaled**；
- root、IK、武器和标记骨通常设为 **Animation**。

这些是常规人形基线，不应盲目覆盖项目已有的复杂设置。先在测试资产或项目副本中验证。

导入时仍选择原 Quinn/Manny 动画正在使用的 Skeleton，并关闭 **Update Skeleton Reference Pose**。如果此前用旧 FBX 覆盖了共享 Skeleton 的参考姿势，应先恢复正确的模板 Skeleton。

不同骨长共享动画通常不需要为每段动画生成副本，但以下内容仍需实际 UE 验证：

- IK Rig、Control Rig 和 Post Process Anim Blueprint；
- 脚底接地与脚锁定；
- 双手握持武器；
- root motion；
- 动画中包含骨骼位移或缩放的特殊轨道；
- 物理资产、布料和碰撞。

官方参考：[Unreal Engine Animation Retargeting](https://dev.epicgames.com/documentation/unreal-engine/animation-retargeting-in-unreal-engine)

## “保留体态：创建独立参考骨架”按钮

这是 v1.2 保留的另一条工作流。它会创建 UE 骨名和层级的独立参考骨架，并同时调整参考关节位置与方向，使源角色当前姿势成为绑定参考姿势。

该结果必须在 UE 中使用独立 Skeleton，再通过 IK Retargeter 或其他重定向流程复用动画。它不适合“导入后直接选择原 Quinn Skeleton”的目标。

对于希望保留体型并尽量共享原 UE 动画的角色，应优先使用 v1.4 的 **仅匹配姿势 + 骨架贴合模型**，因为该模式保留 UE 参考旋转。

## 当前限制

- 优先支持常见人形结构；非常规怪物和多足角色不在自动适配范围内。
- 骨架贴合依据源骨架，不会从网格自动识别解剖关节。
- 自动权重只能作为起点，不能代替肩部、髋部、服装和刚性附件的美术修权重。
- 源没有手指骨时不会生成可靠的独立手指蒙皮。
- 不生成物理资产、布料、LOD、面部绑定、Control Rig、校正姿势或 UE 动画资产。
- Blender 骨架检查与 FBX 往返通过，不等于所有 UE 动画、IK 和动画蓝图均兼容。
- 骨架贴合结果不是“零设置直接复用动画”；UE 位移重定向是必要条件。

## 验证状态

v1.4 女性 Quinn 样例已通过：

- 5,138 顶点、10,276 三角形；
- 89 根骨骼、单一 `root`；
- 无未赋权顶点，权重归一化，每顶点最多 4 个影响；
- 22 个映射关节贴合，测量误差约 `1.2e-7 m`；
- UE 骨骼世界与局部参考旋转保持一致；
- 原权重迁移与混合参考权重均通过基础验证；
- FBX 往返后的参考、抬臂、弯肘、屈膝和转头形变一致；
- 原始源模型、源骨架、目标骨架和参考网格未被修改。

样例仍检测到局部疑似翻折，需要美术检查。当前验证未包含用户 UE 项目中的真实动画播放，因此不作为 UE 运行时兼容保证。

## 源码结构

```text
hunyuan_ue_rebinder/
├── __init__.py          # 面板、参数、操作器与注册
├── mapping.py           # 骨名匹配和身体区域规则
├── core.py              # 输入检查、预览、权重、验证和测试姿势
├── pose_alignment.py    # 保留体型的姿势匹配与参考关节贴合
├── proportions.py       # 独立体态参考骨架工作流
├── geometry.py          # 网格检测、拟合稳定与副本修复
├── exporter.py          # 临时副本 FBX 导出
└── README.md            # 本说明
```

处理过程完全在本地 Blender 中完成，不需要联网或额外 Python 库。

## 问题反馈

请提供：

- Blender 与插件版本；
- 使用的对齐方式、是否开启骨架贴合；
- 源骨架和目标骨架类型；
- 相关骨骼映射；
- 参考姿势和异常动作截图；
- 导出的 `.report.json`；
- UE 使用的 Skeleton、动画资产和 Animation Blueprint 信息。
