# 混元 → UE 骨架换绑助手

**Hunyuan UE Rebinder · Blender Add-on · v1.1.0**

将已有蒙皮的混元 3D 人形角色适配到 Unreal Engine 目标骨架，例如 Manny。插件在 Blender 中提供分步操作面板：选择两套骨架、检查映射、调整外形、检测碎面、生成蒙皮、测试姿势，最后导出 FBX。

工具以目标骨架的参考姿势为基准，在副本上调整源网格并重新绑定。输入模型的几何和骨架数据保留，可在生成结果上继续编辑。

## 功能

- 两个主要输入：UE 目标骨架、带蒙皮的混元源骨架。
- 自动识别源骨架关联的多个网格，可分别选择身体、衣服、头发等。
- 常见混元 / Mixamo / Manny 骨名自动匹配，支持手动修改和 JSON 映射预设。
- 自动适配目标参考姿势，或保留已经手动对齐的源外形。
- 拟合防翻折，以及退化面、重复面、游离顶点、小岛和非流形问题检测。
- 原权重迁移，或混合 UE 参考网格权重；支持肩部权重比例调整。
- 抬臂、弯肘、屈膝、转头测试，以及手工权重修正。
- 骨架与蒙皮检查、FBX 导出、Blender 工作副本保存。

## 环境要求

| 项目 | 要求 / 状态 |
| --- | --- |
| Blender | 插件声明最低版本 4.2；实际测试版本为 Windows Blender 5.2.1 LTS |
| 其他版本与系统 | Blender 4.2–5.1、其他操作系统尚未实机验证 |
| 源角色 | 已有骨架、Armature 修改器和有效蒙皮权重的人形角色 |
| 目标骨架 | 独立的 UE 骨架，优先支持 Manny / 类似人形结构 |
| UE 参考网格 | 可选；用于提供目标蒙皮权重，必须绑定到所选 UE 骨架 |
| 运行依赖 | 使用 Blender 自带 Python 与 NumPy，无需额外安装依赖或连接在线服务 |

插件处理已经导入 Blender 的模型，不负责调用混元 3D 生成服务。使用自己的角色和目标骨架即可，不依赖特定名称的 `.blend` 示例文件。

## 安装与升级

### 安装插件 ZIP

1. 获取插件安装包 `hunyuan_ue_rebinder_v1.1.0.zip`，保持 ZIP 格式。
2. 打开 Blender → **编辑（Edit）→ 偏好设置（Preferences）→ 插件（Add-ons）**。
3. 在右上角菜单选择 **从磁盘安装（Install from Disk）**，选择插件 ZIP。
4. 启用 **混元 → UE 骨架换绑助手**。
5. 将鼠标放在 3D 视图中，按 `N`，打开右侧 **UE 换绑** 页签。

### 从 GitHub 源码制作安装包

GitHub 的 **Code → Download ZIP** 下载的是整个仓库。先解压，将其中的 `hunyuan_ue_rebinder` 文件夹单独压缩成 ZIP，再按上面的步骤安装。

安装包内部应为以下结构，不能在插件文件夹外再套一层仓库目录：

```text
hunyuan_ue_rebinder_v1.1.0.zip
└── hunyuan_ue_rebinder/
    ├── __init__.py
    ├── core.py
    ├── mapping.py
    ├── geometry.py
    ├── exporter.py
    └── README.md
```

### 从 v1.0 升级

先保存工作并禁用旧版插件，再安装新版、重启 Blender 并确认插件已启用。旧结果不会自动更新，需要重新执行 **步骤 3 → 3.5 → 4**。

旧预览没有 v1.1 的拟合参考数据，不能直接进行局部翻折稳定修复。如果旧预览有手工修改，请先另存文件，再重新生成。

## 快速开始

1. 将 UE 角色骨架和混元角色导入同一个 Blender 场景。
2. 在 **UE 换绑** 面板选择 **UE 骨架** 和 **混元骨架**。
3. 点击 **1. 检查输入并识别网格**，确认网格列表和可选的 UE 参考网格。
4. 检查源骨骼到目标骨骼的对应关系，点击 **2. 检查映射**。
5. 点击 **3. 生成 / 更新对齐预览**，检查外形和关节位置。
6. 在 **3.5 · 网格检测与修复** 中检测预览；有问题时先定位，再修复。
7. 点击 **4. 生成换绑模型**，测试抬臂、弯肘和屈膝，再点击 **5. 检查骨架和权重**。
8. 确认外形和动作后，点击 **6. 导出 FBX**；需要保留工作进度时点击 **另存 Blender 副本**。

## 详细操作

### 1. 输入两套骨架

| 输入 | 如何选择 |
| --- | --- |
| UE 骨架 | 目标 Armature 对象，或下级只有一套骨架的外层 Empty 对象 |
| 混元骨架 | 源角色的 Armature 对象，网格应通过 Armature 修改器绑定到它 |
| UE 参考网格 | 检查输入时自动查找，优先选名称含 LOD0 的网格；可手动更换或清空 |

例如，场景中有 `SKM_Manny_Simple` 和 `Armature`：前者可以作为 UE 输入；若它是外层 Empty，也可以直接选择其内部的目标骨架。`Armature` 作为混元输入。这些名称只是示例，插件不要求对象必须使用这些名字。

点击 **1. 检查输入并识别网格** 后，确认勾选了需要处理的源网格。两套输入必须独立，不能把插件生成的预览或结果作为输入。

如果角色带有 Shape Keys，默认会阻止生成。只有接受将当前外形固化到新网格时，才勾选 **烘焙当前形态（不保留形态键）**；源模型的形态键保留。

### 2. 骨骼对应关系

映射表左侧为源骨骼，右侧为目标骨骼。检查自动匹配结果，尤其是左右侧、锁骨、上臂、脊柱、手和腿。

- 有权重的源骨骼必须映射到有效的目标变形骨。
- 红色行表示有权重的骨骼缺少有效映射，需要在右侧搜索框中选择目标。
- 可以将多个源骨骼映射到同一目标骨骼。
- 不要把蒙皮权重映射到 IK 或辅助骨。
- **重新自动匹配** 会覆盖当前映射；需要保留时先点击 **保存映射**。

完成后点击 **2. 检查映射**。使用 **加载映射** 可复用 JSON 预设，但仍需检查它是否适用于当前角色。

### 3. 对齐预览

| 对齐方式 | 适用情况 |
| --- | --- |
| 自动适配目标参考姿势 | 根据骨骼对应关系调整源网格，适用于常规人形换绑 |
| 已手工对齐，保持网格 | 已经自行调整源角色外形和姿势，不希望再次进行自动体型适配 |

保持 **拟合防翻折（保留局部细节）** 开启，点击 **3. 生成 / 更新对齐预览**。结果位于 `换绑_对齐预览` 集合中，重点观察肩部、腋下、裆部、膝盖、头和手。

可以选中预览网格，进入编辑模式调整顶点，或修改网格对象的位置；后续绑定会保留这些预览编辑。**不要移动预览骨架的骨骼。**

**缺失时补回 root** 仅在目标不存在名为 `root` 的骨骼时生效，名称判断忽略大小写。如果目标使用其他名称的正式根骨且需要原样保留，可以关闭该选项。

重新生成预览会替换旧预览。修改源模型、源姿势、目标骨架、映射或拟合参数后，需要重新生成；希望保留手工编辑时先另存文件。

### 3.5 网格检测与修复

1. 将 **检测对象** 设置为 **对齐预览**，点击 **检测网格问题**。
2. 点击 **选中疑似问题面**，进入编辑模式观察问题位置。多个网格时优先检查当前活动网格，否则选择列表中的首个网格。
3. 确认需要处理的类型，再点击 **修复副本网格**。
4. 再次检测并观察外形，确认后继续生成换绑模型。

| 检测项 | 如何处理 |
| --- | --- |
| 退化面、重复索引面、游离顶点 | 修复操作会清理这些无效几何 |
| 疑似翻折、异常面积变化 | 新版拟合参考数据可用于筛查；开启“修复时稳定局部翻折”进行稳定处理后复查 |
| 小型独立网格岛 | 默认保留；确认属于碎片后再开启“删除检测到的小岛（可能是装饰）” |
| 边界、非流形边 | 需要结合结构判断；插件不会自动补洞或全局焊接 |
| 法线方向 | 按需开启“重算法线方向”；重算法线无法消除几何穿插 |

小岛判断同时使用面数和面积阈值。头发、护甲和饰品也可能是独立网格岛，不应只凭检测结果删除。

**修复按检测范围和参数处理网格，不是只修复当前选中的面。** 如需仅删除特定面，请在编辑模式中手动操作。

原模型只允许检测；预览或结果修复前会保留旧网格数据。面板修复操作支持撤销，备份网格名称也记录在对象自定义属性 `hur_geometry_backup` 中。修复保留 UV、材质及剩余顶点的权重。

翻折检测是局部方向与面积筛查，并非完整自相交检测。检测数量为零也不代表模型在所有动作下都不会穿插。

### 4. 生成换绑模型

选择权重方式后点击 **4. 生成换绑模型**：

- **原权重 + UE 参考权重**：按身体区域混合源权重与目标参考网格权重。没有可用参考网格时回退到原权重迁移。
- **仅迁移原权重**：通过骨骼映射迁移源蒙皮，不使用参考表面权重。

以下是新建工作流的默认值，可作为初次尝试的起点，不能保证适合所有衣服和体型：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 头部比例 | 0.95 | 调整拟合后的头部比例 |
| 手部粗细 | 0.88 | 调整手部拟合尺度 |
| 拟合稳定强度 | 0.65 | 约束局部形状，减少拟合翻折 |
| UE 权重比例 | 0.75 | 控制参考网格权重的混合程度 |
| 肩部 UE 权重比例 | 0.90 | 在肩关节附近渐进加强参考权重，仅混合模式有效 |
| 最大转移距离 | 0.20 米 | 超出范围时保留原映射权重 |
| 权重平滑次数 | 6 | 平滑相邻顶点的权重分布 |
| 每顶点骨骼上限 | 8 | 限制每个顶点参与蒙皮的骨骼数量 |

新骨架和网格位于 `换绑_结果` 集合。再次生成会保留并隐藏上一次结果；Blender 可能自动为集合名添加数字后缀。

### 5. 检查姿势和权重

依次测试 **抬臂、弯肘、屈膝、转头**，并从多个视角检查。点击 **参考** 查看参考姿势，点击 **恢复测试前姿势** 返回测试前状态。

v1.1 的 **抬臂** 包含锁骨配合；**只转上臂（压力测试）** 用于单独观察上臂运动造成的变形。这些按钮是简单蒙皮检查，不是完整动画或 IK 测试。

如果肩部明显塌陷或胸部被拉动，按以下顺序检查：

1. 在参考姿势下检查是否已经存在翻折，以及肩关节是否位于合适位置。
2. 检查锁骨、上臂、胸部的骨骼映射。
3. 调整 UE 权重比例、肩部 UE 权重比例或平滑次数，重新生成绑定并对比。
4. 需要局部处理时点击 **手动修正权重**，在 Weight Paint 中修正。
5. 点击 **5. 检查骨架和权重**，通过后再导出。

自动检查包括骨名、层级、参考矩阵、单根结构、有效坐标、Armature 修改器、未赋权顶点、权重归一化和影响数上限，同时记录网格检测结果。检查通过仍需目视确认变形效果。

### 6. 导出 FBX 与保存工作

点击 **6. 导出 FBX**，选择已有目录并填写文件名。插件自动检查结果，在临时副本上按以下设置导出：

- 输出结果网格和目标骨架，单位为厘米。
- 使用参考姿势，不导出当前测试姿势或动画。
- 保留目标全部骨骼，不添加叶骨。
- 可选择 **FBX 内嵌贴图**。
- 生成同名 `.report.json` 检查报告。

例如：

```text
MyCharacter.fbx
MyCharacter.report.json
```

点击 **另存 Blender 副本** 可保存完整场景与可编辑结果；选择不同于当前文件的名称。

在 Unreal 中导入时，选择与输入目标骨架对应的 Skeleton，再检查实际动画、比例和材质。若插件补加了根骨，或输入骨架与现有 Skeleton 不一致，应先核对骨名和层级。当前版本未在目标 Unreal 项目内完成动画兼容性验证。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 安装后找不到面板 | 确认插件已启用，将鼠标移到 3D 视图再按 `N`；升级后重启 Blender |
| 找不到源角色网格 | 检查网格的 Armature 修改器是否指向所选源骨架，仅设置父子关系不足以识别 |
| 提示外层对象包含多个骨架 | 直接选择需要的 Armature 对象 |
| 没有 UE 参考网格 | 可继续使用原权重换绑；混合权重的补充效果不可用 |
| 提示未映射骨骼 / 无效骨骼 | 修正映射表中的目标骨骼，再点击“2. 检查映射” |
| 提示顶点没有有效权重 | 先修正源模型蒙皮，确保参与处理的每个顶点都有有效骨骼权重 |
| 提示负缩放或非均匀缩放 | 在输入副本上修正骨架变换，并确认蒙皮外形正常后重新检查输入 |
| 修改参数后旧结果不能继续使用 | 拟合或映射变化后重新生成预览并绑定；权重参数变化后重新绑定 |
| 原模型突然不见了 | “预览时隐藏输入”会暂时隐藏输入，点击“恢复输入”恢复原可见状态 |
| 碎面修复后还有问题 | 使用“选中疑似问题面”定位；局部翻折、衣物穿插和非流形结构可能需要手工调整 |
| 手指不能独立弯曲 | 源没有独立手指映射时保留整手绑定；需要手动补充对齐和手指权重 |
| 抬臂时已经变形，导出是否会固定成该姿势 | 插件导出的是参考姿势，当前测试姿势不会作为导出动画 |

## 当前限制

- 优先适用于常见人形结构。非常规骨名可手动映射，但自动人体适配与测试姿势依赖常见骨骼命名。
- 体型差异大、厚衣服、肩甲、袖口及裆部可能需要手工修形和权重绘制。
- 不自动补充缺失的精细手指蒙皮，不制作面部绑定、布料、物理资产、LOD、Control Rig、校正动画或动画重定向。
- 有形态键的源网格只能在显式允许后烘焙当前外形，生成网格不保留原形态键。
- 网格诊断和 Blender / FBX 检查不能替代 Unreal 中的实际动画验收。

## v1.1 验证记录

在一个测试角色上完成了 8,503 顶点、16,994 三角形、89 骨骼的完整换绑与 FBX 往返检查：单根骨、没有未赋权顶点，每顶点最多 8 个骨骼影响。

同一模型、同一检测规则下，拟合稳定处理将疑似翻折面从 94 个降至 5 个，顶点数和面数保持不变；仍有残余问题需要人工检查。这是单个样本的结果，不是对所有角色的质量保证。

另验证了原模型保护、修复前备份、UV 和权重保留、小岛删除需显式开启、多网格换绑、只有目标骨架时的回退、已有 `Root` 不重复添加、导出失败清理，以及 ZIP 安装与启用 / 禁用。

```text
├── core.py       # 输入检查、拟合、换绑、验证和姿势测试

```
